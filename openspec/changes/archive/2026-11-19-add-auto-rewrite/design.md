# 设计

## 请求路由

将连接应用逻辑抽为可独立测试的函数。重写控制器创建带随机 token 的请求级任务；注入器收到 CHAT_COMPLETION_SETTINGS_READY 时按 token 查找已冻结的连接快照，设置 source、模型及协议字段。普通请求使用已保存的当前连接，不再读取编辑草稿。

## 事务与兼容

复用 Auto-Rewrite 的原生 swipe 入口、注入、版本和恢复代码。MVU 在 prepare 前按设置短路，关闭时等待、反馈和事件分支均不触发。原版模型路由与大型弹窗不移植。

## 诊断

请求体携带仅当前任务可识别的 Symbol 元数据；序列化为 JSON 时不会发送给后端。注入后删除引用。诊断观察器在发送前读取该元数据，添加 phase/connectionName。控制器另提供有界生命周期事件，写入独立本地记录并在导出时合并，避免改写传输 observer 的状态机。

## 验证

Node 离线测试覆盖单/双连接、跨协议清理、模型继承、无正文日志。语法检查覆盖新增模块。真实酒馆、真实 API、MVU 和浏览器回归单独列为未执行项。
