# 自动重写行为增量

## ADDED Requirements

### 重写连接
- WHEN 重写连接为“与首轮相同” THEN 第二次请求使用首轮已保存连接和模型。
- WHEN 选择其他已保存连接 THEN 仅重写请求使用该连接，可另填模型，不切换全局选择。
- WHEN OpenAI 与 Claude 跨格式重写 THEN 请求 source 与协议字段同步切换且不残留上一连接凭据。

### 重写生命周期
- WHEN 自动重写开启且单角色聊天收到有效新回复 THEN 同楼生成一个新 Swipe 并保留原稿。
- WHEN 自动重写关闭 THEN 不自动发起，仍允许手动重写。
- WHEN 失败、取消或无有效正文 THEN 恢复原稿并显示原因。
- WHEN 用户停止且已有重写正文 THEN 保留当前重写稿与原稿。

### 意见与 MVU
- WHEN 用户未填额外意见 THEN 使用可编辑的简洁基础规则。
- WHEN 用户填写额外意见 THEN 将基础规则与额外意见组合并在任务开始时冻结。
- WHEN MVU 兼容关闭 THEN 不执行 MVU 快照、变量回滚、额外等待或附加 MVU 指令。
- WHEN MVU 兼容开启 THEN 按原项目事务方式处理变量快照与恢复。

### 诊断
- WHEN 开启现有诊断 THEN 记录重写请求的 phase、连接名、模型及已有传输结果。
- WHEN 重写成功、失败、取消或停止 THEN 导出记录包含对应生命周期结果与脱敏原因。
- WHEN 记录任何重写信息 THEN 不保存正文、修改意见、原始响应或认证信息。
